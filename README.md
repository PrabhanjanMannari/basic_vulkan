# Basic Vulkan Renderer

This project is a personal learning exercise to explore the Vulkan graphics API and gain a deeper understanding of modern graphics programming.

The long-term goal is to build a lightweight renderer for visualizing results from my other projects, particularly in **computer vision, SLAM, 3D reconstruction, and object tracking**.

## Disclaimer

This renderer is intended primarily for learning and experimentation. It prioritizes simplicity and ease of development over performance, robustness, and adherence to production-quality software engineering practices.

Several shortcuts and simplifying assumptions are made throughout the implementation.

The application is developed and tested exclusively on my personal development machine. **Portability and compatibility with other hardware, operating systems, or development environments are not guaranteed.**

**This project is not intended for production use.**
